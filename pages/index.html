Cost Modes

Choose the mode matching task complexity. Default: cheapest mode that still verifies.

--fast Low risk · Clear scope
  • Typo fixes
  • 1-2 file edits
  • Known-location config changes
/caveman lite CRG search mem capture skip RTK
--standard Normal development
  • New feature implementation
  • Medium refactoring
  • Local diff review
/caveman full CRG trace mem search RTK (large) OpenSpec optional light review
--deep High risk · Cross-system · Ambiguous
  • Architecture decisions
  • Cross-module debugging
  • Deep research
/caveman ultra CRG arch mem search OpenSpec/spec plan GSD pipeline deep review

Special case: `/tool-research` uses `--quick / --web / --deep` because it routes by evidence source and research depth, not the main execution-cost axis.

Quick Start

Download → Inspect → Run. Three steps to ready.

01

Download Installer

Download first, inspect the content, then run. Default: full install all components.

bash
curl -fsSL -o install.sh https://raw.githubusercontent.com/HunterXing/engineer-shovel/main/install.sh
less install.sh
powershell
Invoke-WebRequest -Uri https://raw.githubusercontent.com/HunterXing/engineer-shovel/main/install.ps1 -OutFile install.ps1
Get-Content install.ps1 | Select-Object -First 50
02

Choose Install Mode

Supports OpenCode / Claude Code across macOS, Linux, and Windows. Recommended installs the core stack; full adds ECC and GSD.

bash
# OpenCode full install (default)
bash install.sh --target opencode

# Core stack: Caveman + RTK + CRG + superpowers + OpenSpec
bash install.sh --target opencode --recommended

# Skill + commands only
bash install.sh --target opencode --minimal

# Install for both OpenCode and Claude Code
bash install.sh --target all
powershell
# OpenCode full install (default)
.\install.ps1 -Mode full -Target opencode

# Core stack: Caveman + RTK + CRG + superpowers + OpenSpec
.\install.ps1 -Mode recommended

# Skill + commands only
.\install.ps1 -Mode minimal

# Install for Claude Code
.\install.ps1 -Target claude
03

Start Using

Load the skill in session or call commands directly. Start with the main workflow commands before reaching for support or platform routes.

text
# Load skill
skill(name="engineer-shovel")

# Or call commands directly
/tool-quick --fast "fix a README typo"
/tool-fix --standard "investigate failing login test"
/tool-plan --standard "plan rollout for X"
/tool-research --quick "compare local patterns for X"

Upstream Tools

Recommended mode installs the core stack. Full mode adds ECC and GSD for deep orchestration.

Tool Version Role
OpenSpec latest Spec-driven artifacts: proposal, specs, design, tasks, verify, archive. CLI installed; project init stays explicit.
ECC v1.10.0 On-demand capability guidance: architecture tradeoffs, security-focused research, integration patterns, and specialized workflows.
GSD v1.39.0 Deep project orchestration: phase execution, structured verification pipeline (verify-work → code-review → ship)
superpowers v5.0.7 Method layer for clarification, TDD, debugging, and verification discipline.
code-review-graph v2.3.2 Local code knowledge graph, MCP review context, impact analysis
claude-mem v12.6.0 Auto-capture cross-session memory: decisions, preferences, bug history. Progressive disclosure (search → timeline → get_observations). SQLite + Chroma.
Caveman v1.7.0 LLM output token compression with enforced 3-tier mode mapping (lite/full/ultra per cost mode)
RTK v0.38.0 Shell/tool output compression with smart trigger (output >500 lines only)
