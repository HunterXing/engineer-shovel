Cost Modes

Choose the mode matching task complexity. Default: cheapest mode that still verifies.

--fast Low risk · Clear scope
  • Typo fixes
  • 1-2 file edits
  • Known-location config changes
/caveman lite CRG search skip RTK
--standard Normal development
  • New feature implementation
  • Medium refactoring
  • Local diff review
/caveman full CRG trace RTK (large) GSD verify
--deep High risk · Cross-system · Ambiguous
  • Architecture decisions
  • Cross-module debugging
  • Deep research
/caveman ultra CRG arch GSD pipeline review-work

Quick Start

Download → Inspect → Run. Three steps to ready.

01

Download Installer

Download first, inspect the content, then run. Default: full install all components.

bash
curl -fsSL -o install.sh https://raw.githubusercontent.com/HunterXing/engineer-shovel/main/install.sh
less install.sh
02

Choose Install Mode

Supports OpenCode / Claude Code, minimal / recommended / full modes.

bash
# OpenCode full install (default)
bash install.sh --target opencode

# Skill + commands + Caveman
bash install.sh --target opencode --recommended

# Skill + commands only
bash install.sh --target opencode --minimal

# Install for both OpenCode and Claude Code
bash install.sh --target all
03

Start Using

Load the skill in session or call commands directly.

text
# Load skill
skill(name="engineer-shovel")

# Or call commands directly
/tool-quick --fast "fix a README typo"
/tool-review --fast
/tool-research --deep "compare X options"
/tool-graph update
