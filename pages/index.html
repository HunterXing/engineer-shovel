成本模式

根据任务复杂度选择对应模式，默认选择能验证结果的最低成本路径。

--fast 低风险 · 明确目标

快速开始

下载 → 检查 → 运行，三步完成安装。

01

下载安装脚本

先下载、检查内容，再执行。默认全量安装所有组件。

bash
curl -fsSL -o install.sh https://raw.githubusercontent.com/HunterXing/engineer-shovel/main/install.sh
less install.sh
02

选择安装模式

支持 OpenCode / Claude Code，minimal / recommended / full 多种模式。

bash
# OpenCode 全量安装（默认）
bash install.sh --target opencode

# Skill + 命令 + Caveman
bash install.sh --target opencode --recommended

# 只安装 Skill + 命令
bash install.sh --target opencode --minimal

# 同时安装到 OpenCode 和 Claude Code
bash install.sh --target all
03

开始使用

在会话中加载技能或直接调用命令。

text
# 加载技能
skill(name="engineer-shovel")

# 或直接调用命令
/tool-quick --fast "修一个 README typo"
/tool-review --fast
/tool-research --deep "比较 X 的方案"
/tool-graph update
